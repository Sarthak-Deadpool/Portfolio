# Portfolio



A personal portfolio website built with HTML, CSS, and JavaScript.

## Sections
- MySection — animated role text using Typed.js
- Projects — hover effect cards with tech stack
- Skills — tech logo grid with blob animation
- Contact — message form
- Footer — social links

## File Structure
Portfolio/
├── index.html
├── header.css
├── project.css
├── skills.css
├── contact.css
├── footer.css
├── mobilemediaquery.css
└── images/

## Responsive
- Mobile (max 600px) — stacked layout, icons hidden
- Tablet (601px–1024px) — horizontal navbar, two-column skills

## How to Run
Open index.html in any browser. No setup needed.
